# Simulator 購買測試步驟

- 依序完成以下 12 項。
- 使用本機模擬商店，不扣款。
- 不需切換 Apple 帳號。

| 項目 | 這段要測什麼 |
| --- | --- |
| [1–4](#1-商品與價格正確載入) | 價格、取消、購買失敗、還原查無結果。 |
| [5–7](#5-月費購買成功重開後保留權益與帳目) | 月費、年費、重開 App、還原購買。 |
| [8–12](#8-到期後回到免費版達上限仍可記帳) | 訂閱到期、免費額度、停用與刪除類別。 |

- **開始前**
    - [環境準備](no17_r15_local_storekit.md#環境準備)。
    - 模擬商店已啟用。
    - 商店沒有有效訂閱。
    - 購買失敗設定已關閉。
    - App 使用繁體中文，停在設定頁。
    - App 為免費版。
- **執行安排**
    - AI 或使用者依本輪約定操作。
    - 需要觀看的畫面，先停下再繼續。
    - 遇到等待確認，完成後才做下一步。
    - 商店設定與重開方法見[執行說明](no17_r15_local_storekit.md)。
- **記錄結果**
    - 每個步驟都留下本次測試紀錄。
    - 畫面結果保留截圖或過程觀察。
    - 商店狀態另保留系統證據。
    - 取證方法沿用執行說明。
- **單獨測其中一項**
    - 先備妥該項的開始條件。

## 1. 商品與價格正確載入

- **開始時**
    - 停在設定頁，App 為免費版。
    - 商店沒有有效訂閱。
    - 不需先建立帳目。

| 操作 | 預期結果 |
| --- | --- |
| 點升級至 Premium。 | 升級頁開啟。月費、年費、還原購買可見。 |
| 點月費。 | **US$0.99／月**。 |
| 查看續訂說明與立即升級按鈕。 | 續訂金額與週期相符。按鈕可點。 |
| 點年費。 | **US$9.99／年**。 |
| 查看續訂說明與立即升級按鈕。 | 續訂金額與週期相符。按鈕可點。 |

- **保留結果**
    - 保留月費與年費選取後的畫面。
    - 幣別可顯示 US$、USD 或美元符號。
    - 兩種價格均為測試資料。
- **完成後**
    - 停在升級頁，年費已選取。
    - 仍為免費版，可接第 2 項。

## 2. 取消購買後仍維持免費版

- **開始時**
    - 停在升級頁，App 為免費版。
    - 商店沒有有效訂閱。
    - 購買失敗設定已關閉。

| 操作 | 預期結果 |
| --- | --- |
| 選月費。 | 月費已選取。 |
| 點立即升級。 | Xcode 購買視窗開啟。 |
| 取消購買。 | 回到升級頁。沒有失敗提示或持續轉圈。 |
| 點左上角關閉按鈕。 | 回到設定。升級至 Premium 仍可見。 |
| 再次點升級至 Premium。 | 升級頁開啟。 |
| 選月費，點立即升級。 | 購買視窗再次開啟。 |
| 再次取消購買。 | 回到升級頁。沒有失敗提示或持續轉圈。 |
| 關閉升級頁。 | 回到設定。升級至 Premium 仍可見。 |

- **觀察取消過程**
    - 兩次都從取消開始，觀察到回到設定頁。
    - 記錄是否出現失敗提示。
    - 保留再次叫出購買視窗的結果。
    - 最後一張截圖不能代替過程觀察。
- **完成後**
    - 停在設定頁，仍為免費版。
    - 沒有新增購買或帳目。
    - 可接第 3 項。

## 3. 購買失敗後仍可重試

- **開始時**
    - 停在設定頁，App 為免費版。
    - 商店沒有有效訂閱。

| 操作 | 預期結果 |
| --- | --- |
| [設定下一次購買失敗](no17_r15_local_storekit.md#商店控制)，等待成功。 | 設定成功。商店沒有有效訂閱。 |
| 升級至 Premium → 月費 → 立即升級。 | 購買視窗開啟。 |
| 確認訂閱，保留提示畫面。 | 顯示購買失敗提示。 |
| 關閉失敗提示。 | 回到升級頁。載入結束，按鈕可操作。 |
| 核對商店狀態。 | 沒有有效訂閱。App 維持免費版。 |
| 關閉購買失敗設定，等待成功。 | 購買失敗設定已關閉。 |
| 再點立即升級。 | 購買視窗再次開啟。 |
| 取消購買，再關閉升級頁。 | 回到設定。升級至 Premium 仍可見。 |

- **完成後**
    - 仍為免費版，沒有新增訂閱。
    - 購買失敗設定已關閉。
    - 可接第 4 項。

    - 沒有新增帳目。
    - 接著準備第 5 項資料。

## 5. 月費購買成功，重開後保留權益與帳目

- **開始時**
    - 停在設定頁，App 為免費版。
    - 商店沒有有效訂閱。
- **準備共用資料**
    - 依[共用資料準備](no17_r15_local_storekit.md#共用資料準備)建立本場假資料。
    - 第 5 至 12 項共用，保留到整場結束。
- **帳戶與類別**
    - 帳戶共 3 個：錢包、銀行、備用。
    - 幣別均為 TWD，建立時餘額均為 0。
    - 支出類別：餐飲、交通、購物、娛樂、醫療。
    - 收入類別：薪資、獎金。
    - 類別共 7 個，全部啟用。
- **原有支出**
    - 金額 100 元，錢包／餐飲。
    - 備註： "R15 原有支出"。
    - 日期為本日 12:00。
- **原有轉帳**
    - 錢包轉銀行，轉出與轉入均為 200 元。
    - 日期為本日 12:05。
- **日期**
    - 本日固定為準備資料時的 App 日期。
    - 跨日續做仍沿用，時區保持不變。
    - 完整欄位定義見[測試資料](no1_fixtures.md#r15-本機商店資料)。
- **先核對資料**
    - 首頁期間切為全，展開分類查看紀錄。
    - 應有 1 筆支出與 1 筆轉帳。
    - 到管理帳戶、管理類別核對數量。
    - 餘額應為錢包 -300、銀行 200、備用 0。
    - 後續都用相同方式比對。
- **暫用項目**
    - 稍後會新增 "測試帳戶 4" 與 "測試類別 8"。
    - 兩者都不放入帳目，後面的同名項目也一樣。

| 操作 | 預期結果 |
| --- | --- |
| 設定 → 升級至 Premium → 月費 → 立即升級。 | Xcode 購買視窗開啟。 |
| 在購買視窗確認訂閱。 | 購買成功。 |
| 關閉成功提示。若顯示 OK 就點 OK。 | 升級頁自動關閉。升級至 Premium 消失。 |
| 核對商店的有效訂閱。 | 月費有效。商品代碼符合本場設定。 |
| 設定 → 管理帳戶 → 右上角新增。 | 新增帳戶畫面開啟。 |
| 輸入 "測試帳戶 4"，幣別 TWD、餘額 0，再點完成。 | 新增成功，共 **4 個帳戶**。 |
| 設定 → 管理類別 → 右上角新增。 | 新增類別畫面開啟。 |
| 輸入 "測試類別 8"，選支出，點完成。 | 新增成功，共 **8 個類別**。 |
| 用本場工具[完全關閉並重開 App](no17_r15_local_storekit.md#完全關閉後重開)，等待重開完成與商店就緒。 | 原帳目與測試身分保留。模擬商店就緒。 |
| 打開設定。 | 升級入口隱藏。升級頁未自動開啟。 |
| 查看管理帳戶。 | "測試帳戶 4" 保留，餘額 0。 |
| 查看管理類別。 | "測試類別 8" 保留。 |
| 核對原有支出、轉帳與餘額。 | 原有紀錄與餘額不變。 |
| 管理帳戶 → "測試帳戶 4" → 刪除帳戶，確認刪除。 | 測試帳戶消失，剩下 **3 個帳戶**。 |
| 管理類別 → "測試類別 8" → 刪除類別，確認刪除。 | 測試類別消失，剩下 **7 個類別**。 |
| 返回設定。 | 升級入口仍隱藏。 |

- **完成後**
    - 月費有效，原有帳目保留。
    - 第 6 項先重設模擬商店，再獨立測年費。

## 7. 點還原購買後恢復付費權益

    - 打開升級頁，再建立有效月費交易。
    - 保留升級頁，不要關閉。
- **開始條件**
    - 商店已確認月費有效。
    - 畫面仍可點還原購買。
    - 3 個帳戶、7 個類別。
    - 1 筆支出、1 筆轉帳。
    - 餘額為錢包 -300、銀行 200、備用 0。

    - 先記為尚未測試。

    - 不用重裝、清帳目或指定付費等級製造入口。
